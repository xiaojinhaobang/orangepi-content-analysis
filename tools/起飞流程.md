# 起飞流程（2026-10-19 固定）

## 0. 开机

- 上电后等约 2 分钟，`flight-link` 自启（含 cartographer）。
- 自启已包含：`imu_pub` → `fc_odom` → cartographer、`fcstat_log`、`arm_trigger`。

## 1. 起飞前（每次必做，约 5 秒）

```bash
bash ~/diag/prep.sh
```

必须看到「全部通过」。任何 FAIL 都不要起飞，按该行提示处理。

## 2. 起飞

1. 遥控 CH5 中位、CH6 高位解锁。
2. 油门推到中位附近（430~620）。
3. `arm_trigger` 自动发 `/gs/start` → `mission_node` 先做位姿闸门（连续 5 帧 <2 cm）→ 通过后发 `0x66` 起飞。

## 3. 飞行中

- `auto_guard`：横移 >25 cm / 速度 >20 cm/s / 定位丢失 1 s → 自动轻降；掉落 >50 cm → 停桨。
- 手动快停：`touch /tmp/guard_land`。

## 4. 落地后

- 遥控锁定。飞行日志在 `~/traces/rec_*.log`。

## 关键配置（当前）

| 项 | 值 |
|---|---|
| dead_reckon | `passthrough=true`、`gate_enable=false`、`max_step_cm=5` |
| cartographer | `tracking_frame=imu_link`、`use_imu_data=true`、`use_odometry=true`、`provide_odom_frame=true`、`optimize_every_n_nodes=0`、`min_range=0.12` |
| 频率 | `/fc_vel`、`/height`、`/fc_pwm`、`/fc_target` 50 Hz；`/imu` 200 Hz |
| PID | 取 `dr_base`、`kp_xy=0.7`、起飞 XY 限速 8 cm/s |

## 已知风险

- **场地磁干扰**：体检里的「罗盘 vs SLAM 航向」在场地若 >3° 会被拦；飞行中该差值摆动 60~70° 的场次会飘（10-16、10-18 实测）。
- **机脚**：起落架断裂过的机体，起飞前确认四脚着地、机体水平。
