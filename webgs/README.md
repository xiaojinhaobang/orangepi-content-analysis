# D题 · 单板双面盘点 · **网页版地面站**

给队友用的浏览器版地面站。**零依赖**：只要有 Python 3，不用装 PySide6/Qt。
一台电脑跑起来，同网段的手机、平板、其他电脑用浏览器打开即可看盘点结果、下任务。

---

## 一、怎么跑

### 方式 A（推荐给队友）：跑在香橙派上，输网址就能用

网页版已经装在香橙派上并随控制台开机自启，**队友什么都不用装，浏览器直接开**：

```
http://172.25.105.210:8081
```

（板子 IP 随热点变，换网后先确认板子 IP；8080 被板上别的服务占着，我们用 8081。）

手动重启它（一般不用）：

```bash
cd ~/diag/webgs && python3 server.py --ros --port 8081
```

`--ros` = 直接订阅机上话题（不占 UDP 8888），「开始任务」会发 `/gs/start`。
日志在 `/tmp/webgs.log`。

### 方式 B：跑在某台电脑上（机载发 UDP 给它）

```bash
python server.py                       # 默认 http://0.0.0.0:8080，机载 IP 172.25.105.210
python server.py --port 8080 --drone-ip 172.25.105.210
python server.py --autoconnect          # 启动就连机载
```

Windows 直接双击 **`启动网页地面站.bat`**（会自动开浏览器）。

启动后窗口会打印本机地址，例如：

```
网页版地面站：http://172.25.105.29:8080   （同网段手机/电脑都能开）
```

**队友怎么用**：连同一个 Wi-Fi，浏览器打开 `http://<跑服务那台电脑的IP>:8080`。
（手机连不上先查两件事：① 电脑防火墙是否允许 Python；② 是不是同一个网段。）

## 二、页面上有什么

- **链路/任务**：填机载 IP + UDP 端口 → 连接；「▶ 开始任务（遍历盘点）」下发 `START 0`；「内置模拟」没飞机也能演示；「清空复位」
- **无人机状态**：状态 / 高度 / 电量 / 识别报送 / 已盘点进度条
- **遍历流程阶段**：准备 › 起飞 › B面扫描 › 换面 › A面扫描 › 结果核对 › 降落 › 完成
- **盘点结果总览**：12 格（A 面 6 + B 面 6），每格显示位置名、**参考货号**、实际货号
  —— 与参考一致标 <span>✓</span>（绿），不同标 ≠（橙），未盘点显示 —
- **货物查询**：输入货号 → 显示坐标位
- **事件日志**：最近 60 条

> 参考货号来自《D题货架盘点-香橙派方案基线》§1.1 的离线样本（A 13/14/17/15/12/16、B 8/11/9/7/5/6）。
> **现场货号是随机的**，参考值只做对照，正式识别一律现场解码。

## 三、链路说明

```text
浏览器 ──HTTP──► server.py ──UDP 8888──► 香橙派 gs_bridge ──► ROS
   ▲                 │
   └── 状态/结果 ◄────┘   （EVENT 货号+位置 / STATUS 状态+高度）
```

帧协议与桌面版完全一致：`AA 55 | type | len | payload | sum`（小端）。

⚠ **UDP 8888 是独占端口**：网页版和桌面版**不要同时开**，否则只有一个能收到数据（表现是"连上了但一直没数据"）。

## 四、自检

```bash
python test_webgs.py
```

覆盖：页面可访问 → 空状态 12 格 → 参考货号带出 → **UDP 收发（发 STATUS/EVENT 进去看落格）** →
模拟跑完 12 格 → 阶段推算 → 查询/复位/未连链路提示。全绿即本机可用。

## 五、目录

```
server.py             HTTP 服务 + UDP 链路 + 状态机（标准库）
sim.py                内置模拟机载端（时间线，无 Qt）
protocol.py           帧协议（与桌面版/机载端一致）
layout.py             场地几何 + 遍历顺序 + 参考货号（单一来源）
static/index.html     前端页面（一个文件，无外部依赖）
test_webgs.py         自检
启动网页地面站.bat     Windows 一键启动
```

## 六、和桌面版的关系

桌面版（`桌面\学习资料\D题地面站`，PySide6）功能更全（定点盘点页、航线图、二维码显示）；
网页版只做**遍历盘点的看板 + 下发任务**，胜在队友不用装环境、手机就能看。
两者共用 `protocol.py` / `layout.py`，口径一致。
